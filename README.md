## 研究成果

### 推荐算法方案：两阶段流水线

```
输入解析（网表 + DXF板框 + 微带拓扑）
        ↓
阶段一：布局（约束驱动模拟退火）
  · 能量函数：HPWL + 交叉penalty + 边界penalty
  · 功率管/接口固定 → 只优化匹配网络器件位置
        ↓
阶段二：布线（分层迷宫 + A*路径搜索）
  · 栅格化 + 障碍标记
  · 按网络长度降序布线
  · 宽度固定，占用栅格标记
        ↓
后处理（mitered弯角补偿 + DRC + Gerber/DXF输出）
```

### 核心设计约束

- **单层PCB**：禁止过孔，全平面接地
- **微带宽度预定**：根据功率/频率计算一次，后续固定
- **功率管固定**：大功率晶体管位置由热/机械设计决定
- **DXF输入**：支持导入板框和接口坐标
- **微带拓扑**：直线/U形/L形/T形/十字形，预定义模板

## 局限性

- 不支持多层PCB
- 不优化微带宽度
- 无电磁仿真集成
- 拓扑需手动指定
