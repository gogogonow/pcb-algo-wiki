## 研究成果

### 推荐算法方案：五阶段迭代架构（v2）

```
┌─────────────────────────────────────────────────────────────────┐
│ PHASE 1: 全局拓扑规划（FLUTE）                                    │
│   粗粒度路由骨架，估算全局拥塞                                     │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PHASE 2: 区域分解 + Net-Ordering                                 │
│   固定微带线 → 动态障碍区域                                       │
│   RLC shunt → 按主干分组（区域划分）                             │
│   Net-Ordering：约束最严的线先布                                 │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PHASE 3: 区域内详细布线（Zone ILP）                              │
│   规模<20节点 → ILP 精确求解                                     │
│   规模>20节点 → A* + 拥塞代价（效率优先）                        │
│   固定线标记为障碍，不参与优化                                     │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PHASE 4: Ripup-Reroute 迭代优化 ⭐（核心改进）                  │
│   识别拥塞区域 → Ripup（移除灵活走线）→ Reroute（重新求解）     │
│   固定线永远保护，不参与 ripup                                   │
│   可中断、可控制计算时间                                          │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PHASE 5: 几何精化 + 后处理                                       │
│   梯度下降路径松弛 + target_length滑动 + 弧形弯角 + DRC         │
└─────────────────────────────────────────────────────────────────┘
```

### 核心升级（v1 → v2）

| 维度 | v1（简单场景） | v2（复杂场景） |
|------|---------------|---------------|
| **场景** | 低密度RLC、软约束 | 高密度RLC、无交叉硬约束 |
| **架构** | 一次性ILP求解 | **Ripup-Reroute迭代优化** |
| **ILP规模** | 全局联合求解 | **区域内子问题（可控）** |
| **拓扑分裂** | 一次性处理 | **迭代自然重优化** |
| **计算时间** | 不可预测 | **可中断控制** |
| **固定线保护** | 区域分解隐式 | **Ripup显式保护** |

### 架构决策树

```
电路规模 < 20节点（小型）
  └── 路线A：Zone ILP 直接求解（无需 Ripup-Reroute）

电路规模 20-100节点（中大型）
  ├── 高密度RLC + 无交叉硬约束
  │   └── 路线B（推荐）：FLUTE + Zone ILP + Ripup-Reroute
  └── 低密度 + 软约束
      └── 路线A简化版：Zone Decomp + A*

电路规模 > 100节点（大型）
  └── 路线C：分层 Ripup-Reroute（hierarchical）
```

### 核心设计约束

- **单层PCB**：禁止过孔，全平面接地
- **微带宽度预定**：根据功率/频率计算一次，后续固定
- **功率管固定**：大功率晶体管位置由热/机械设计决定
- **DXF输入**：支持导入板框和接口坐标
- **微带拓扑**：直线/U形/L形/T形/十字形，预定义模板
- **无交叉硬约束**：交叉数量必须为0

## 局限性

- 不支持多层PCB
- 不优化微带宽度
- 无电磁仿真集成
- 拓扑需手动指定
