# 功放PCB单层自动布线

> 固定微带线 + 灵活走线 | 高密度 RLC shunt | 无交叉硬约束

---

## 核心方案

**直接用 CP-SAT 建模范题，一个模型涵盖所有约束，无需分阶段。**

---

## 约束 → CP-SAT 原语

| 约束 | CP-SAT 原语 |
|------|------------|
| 无交叉（硬） | `AddNoOverlap` |
| 路径连通性 | `AddCircuit` |
| 目标长度 | `AddLinearExpression` |
| 过孔密度 | `AddCumulative` |
| 固定微带线 | 预布线固定值 |

---

## 算法流程

```
输入YAML → 网格离散化 → CP-SAT建模 → 求解器 → 路径坐标
```

1. **网格构建**：亚微米精度（1μm）离散化 PCB 坐标
2. **变量创建**：每条灵活边在每个网格位置创建一个 BoolVar
3. **约束注入**：AddCircuit（连通）+ AddNoOverlap（无交叉）+ 长度约束
4. **求解**：OR-Tools CP-SAT，多核并行，< 1s（简单场景）
5. **结果提取**：从 BoolVar 矩阵还原为 (x,y) 坐标序列
