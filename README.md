# 功放PCB单层自动布线——最优方案

> 场景：固定微带线 + 灵活走线 | 高密度 RLC shunt | 无交叉硬约束

---

## 结论

**直接用 CP-SAT 建模范题，一个模型求全局最优，无需分阶段。**

---

## 约束 → CP-SAT 原语映射

| 约束 | CP-SAT 原语 |
|------|------------|
| 无交叉（硬） | `AddNoOverlap` |
| 路径连通性 | `AddCircuit` |
| 目标长度 | `AddLinearExpression` |
| 过孔密度 | `AddCumulative` |
| 固定微带线 | 预布线固定值 |

---

## 为什么不需要分阶段

分阶段是**规模妥协**：当问题超出求解器能力时才拆解。

本场景变量规模（10²–10³），CP-SAT **一次性求解 < 1 秒**，分阶段反而产生局部最优和迭代开销。
