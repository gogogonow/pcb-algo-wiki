# 布线算法选型深度分析报告

> 基于 Graph-Topology 数据结构的功放 PCB 单层自动布线算法全面对比

---

## 1. 背景与输入格式

### 1.1 Graph-Topology 数据结构

用户定义的 YAML 输入格式本质是**混合图**：

```yaml
nodes:
  node_A: { type: "junction" }
  node_B: { type: "junction" }
  node_shunt_tap:
    type: "component_pad_junction"
    description: "吸附并联器件的焊接点"

edges:
  tl_segment_part1:  # 被打断的微带线段1
    type: "microstrip"
    connections: [ "node_A", "node_shunt_tap" ]
    constraint: { width: 1.0, target_length: 4.0 }

  tl_segment_part2:  # 被打断的微带线段2
    type: "microstrip"
    connections: [ "node_shunt_tap", "node_B" ]
    constraint: { width: 1.0, target_length: 6.0 }

  c_shunt_match:  # 并联接地电容
    type: "lumped_capacitor"
    connections: [ "node_shunt_tap", "GND_REF" ]
    parameters: { value_pF: 5.6, package: "0402" }
```

### 1.2 数据结构特性

| 特性 | 说明 |
|------|------|
| **混合图** | 分布参数边（microstrip）+ 集总参数边（RLC）共存 |
| **边分裂** | 吸附 RLC 器件时，原边被拆分为两条独立 segment |
| **长度滑动** | `target_length` 是连续变量，沿线滑动优化 |
| **拓扑变形** | 边的分裂/合并是核心拓扑操作 |
| **GND_REF** | 触发自动接地过孔生成 |
| **component_pad_junction** | 携带寄生参数，影响局部几何形状 |

## 2. 业界算法全对比

### 2.1 算法分类

```
路由算法
├── 栅格搜索类
│   ├── A* (及其变体：IDA*, SMA*, D* Lite)
│   └── MazeRouter (Lee's algorithm 改进)
├── 几何构造类
│   ├── FLUTE (Steiner 树构造)
│   ├── 几何求解器 (Gradient-Based Path Relaxation)
│   └── 最近邻投影 (Nearest-Neighbor Projection)
├── 连续空间探索类
│   ├── RRT-Connect
│   └── PRM (Probabilistic Roadmap)
├── 工业标准类
│   ├── 电弧路由 (Arc Routing)
│   └── 层叠布线 (Multi-layer routing)
└── 前沿研究类
    ├── Apollo (2024, GPU 加速)
    ├── DiffCkt (2024, 扩散模型)
    └── 强化学习布局
```

## 3. 各类算法深度分析

### 3.1 A* (及其变体) — 不推荐

**现状：** A* 是教科书级经典算法，在 EDA 工具中广泛应用。但面对本场景的 Graph-Topology 输入，存在根本性不匹配。

| 维度 | 表现 | 评分 |
|------|------|------|
| 栅格依赖 | 离散搜索空间，与 `target_length` 连续滑动冲突 | ❌ |
| 宽度变化 | 宽度不同需重建栅格，开销巨大 | ❌ |
| 转角处理 | 对角移动无法原生表达 mitered/弧形弯角 | ❌ |
| 多线协调 | 依次布，先布的边成为后布的边的障碍 | ❌ |
| target_length 滑动 | 不支持，参数空间与搜索空间分离 | ❌ |
| GND_REF 处理 | 需后处理规则，无法原生集成 | ⚠️ |

**结论：** A* 适合"粗略快速扫通"的场景，不适合精度要求高、参数需精细调节的功放 PCB 场景。

---

### 3.2 FLUTE — ⭐⭐⭐ 主干拓扑首选

**来源：** Cadence / MIT，联合创始人为 Prof. Chong(CHI CHU)。

**核心思想：** 用预计算的查找表直接构造最优或近似最优 Steiner 树，避免穷举搜索。

```
特点：
- 速度极快（查找表 O(n log n)）
- 适合多点到多点拓扑（总线、星形、树形）
- 工业级验证（Cadence 布局工具核心算法）
```

| 维度 | 表现 | 评分 |
|------|------|------|
| 栅格依赖 | 无，离散点构造 | ✅ |
| 宽度变化 | 需扩展支持（每条边独立宽度） | ⚠️ |
| 转角处理 | 直线段构造，无弯角建模 | ⚠️ |
| 多线协调 | 优，Steiner 树拓扑天然协调多点 | ✅ |
| target_length 滑动 | 不直接支持（拓扑固定，长度作为后处理） | ⚠️ |
| GND_REF 处理 | 不支持，需扩展 | ❌ |
| **最佳适用场景** | **Doherty 功放功率合成/分配的多点拓扑（主干预留）** | ⭐⭐⭐ |

**与 Graph-Topology 的契合点：**
- 多个功率管的分支并联 → FLUTE 的 Steiner 树
- 但 `target_length` 滑动优化需要额外层次

---

### 3.3 几何求解器 (Gradient-Based Path Relaxation) — ⭐⭐⭐⭐⭐ 核心推荐

**核心思想：** 将路径规划从"搜索"转化为"优化"。

```
数学表述：
min  E(path)
s.t. width(path) = w_fixed
     clearance(path, obstacles) ≥ d_min

其中 E(path) = ∫₀ˡ length(s) ds + λ₁·bend_penalty + λ₂·impedance_error
```

**优化方式：** 梯度下降 + 约束投影（P projected gradient descent）。

| 维度 | 表现 | 评分 |
|------|------|------|
| 栅格依赖 | 无，连续空间最优 | ✅ |
| 宽度变化 | 天然支持（无栅格化） | ✅ |
| 转角处理 | clothoid / mitered / arc 后处理 | ✅ |
| 多线协调 | 联合优化（非依次布） | ✅ |
| target_length 滑动 | 梯度直接驱动连续变量 | ✅✅ |
| GND_REF 处理 | 后处理规则引擎触发 | ✅ |
| **最佳适用场景** | **微带线精细路径优化 + 长度滑动** | ⭐⭐⭐⭐⭐ |

**与 Graph-Topology 的完美契合：**

| Graph-Topology 操作 | 几何求解器支持方式 |
|---------------------|-------------------|
| 边的分裂（插入 RLC） | 分裂点位置作为独立优化变量 |
| target_length 滑动 | 路径长度 → 梯度直接驱动 |
| component_pad_junction | 节点处叠加寄生参数模型 |
| GND_REF → 过孔 | 规则引擎：检测到即触发 |
| 宽度固定约束 | 代价函数中硬约束 |

---

### 3.4 电弧路由 (Arc Routing) — ⭐⭐⭐⭐ 高频/毫米波首选

**工业背景：** 射频电路中，弯角不是尖锐折线，而是**圆弧或带切角的弧**。这在传输线理论中有明确依据：弧形弯角的阻抗不连续性远小于直角或 mitered 弯角。

**数学表述：**
```
弯角损耗补偿：
ΔZ/Z ≈ (π/4)·(w/R)²   （对于 90° 圆弧弯角）
其中 w = 线宽，R = 弯角半径

mitered 弯角补偿：
ΔZ/Z ≈ (π/4)·(w/d)² · sin²(θ)
其中 d = 切角深度，θ = 弯角角度
```

| 维度 | 表现 | 评分 |
|------|------|------|
| 栅格依赖 | 无，连续空间 | ✅ |
| 宽度变化 | 天然支持 | ✅ |
| 转角处理 | 工业最优（弧形） | ✅✅ |
| 多线协调 | 联合优化 | ✅ |
| target_length 滑动 | 梯度直接驱动 | ✅ |
| GND_REF 处理 | 规则引擎 | ✅ |
| **最佳适用场景** | **高频毫米波（>10GHz）功放 PCB，弯角精度决定性能** | ⭐⭐⭐⭐ |

**与几何求解器的组合：** 电弧路由作为几何求解器的**后处理阶段**，将梯度下降输出的折线段替换为精确弧形曲线。

---

### 3.5 RRT-Connect — ⭐⭐ 复杂禁止区保底

**核心思想：** 随机树扩展 + 贪心双树连接，连续空间探索。

| 维度 | 表现 | 评分 |
|------|------|------|
| 栅格依赖 | 无 | ✅ |
| 宽度变化 | 需扩展支持 | ⚠️ |
| 转角处理 | 随机树，结果不确定 | ⚠️ |
| 多线协调 | 不擅长 | ❌ |
| target_length 滑动 | 不支持 | ❌ |
| 复杂禁止区 | 强，适合异形板框 | ✅ |

**适用场景：** 复杂禁止区（大量过孔禁入区、异形板框）时的保底方案，用于为几何求解器提供初始路径。

**结论：** 作为几何求解器的"路径探索器"，而非主力路由器。

---

### 3.6 Apollo (2024) — ⭐⭐⭐⭐ 参考级开源实现

**出处：** ScopeX-ASU/Apollo (GitHub), GPU 加速 PIC 单层波导自动布局布线。

**核心数据：**
- 单层波导路由成功率：**94.79%**
- 关键创新：GPU 并行 + 学习式热估计
- 开源，适合作为baseline对比

**对本场景的参考价值：**
- 同样是单层、宽度固定、拓扑分裂的场景
- 可借鉴其 GPU 加速思路（如果未来做大规模电路）
- 但其波导结构与微带线有差异（边界条件不同）

## 5. 最优算法组合方案

### 5.1 两层架构

```
┌──────────────────────────────────────────────────────────────┐
│ 第一层：拓扑规划层 (Topology Planning)                        │
│  输入：Graph-Topology YAML + 板框 DXF                        │
│  输出：微带线主干拓扑（多点到多点连接关系）                      │
│  算法：FLUTE（Steiner 树构造）                                │
│  原因：功率合成/分配结构天然是多点拓扑，FLUTE 效率最高          │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│ 第二层：几何优化层 (Geometric Optimization)                   │
│  输入：拓扑规划结果 + target_length 约束 + 禁止区              │
│  输出：物理坐标 + 精确路径 + 过孔位置                          │
│  算法：几何求解器（梯度下降路径松弛）                          │
│  特点：                                                        │
│    · target_length 作为优化变量，梯度直接驱动                   │
│    · 吸附点滑动 → 路径"推拉门"式更新                          │
│    · 联合优化所有路径，无栅格化                               │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│ 后处理阶段 (Post-Processing)                                  │
│  1. 电弧路由：将折线段替换为弧形弯角（高频场景）               │
│  2. GND_REF 规则引擎：生成接地过孔                            │
│  3. 寄生参数计算：在 component_pad_junction 处叠加寄生模型      │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 决策树

```
场景判断：
├── 标准微带线（<10GHz） + 无复杂禁止区
│   └── 几何求解器（梯度下降）→ 电弧后处理（可选）
│
├── Doherty 功率合成/分配结构（多点拓扑）
│   └── FLUTE（拓扑规划）+ 几何求解器（路径优化）
│
├── 复杂禁止区（异形板框、大量禁入区）
│   └── RRT-Connect（初始探索）+ 几何求解器（精细化）
│
└── 高频毫米波（>10GHz）+ 弯角精度要求极高
    └── 几何求解器 + 电弧路由后处理（必须）
```

## 6. 与 Graph-Topology 的完整映射

### 6.1 拓扑操作 → 算法操作

| Graph-Topology 操作 | 布线算法响应 |
|---------------------|-------------|
| 边的分裂（吸附 RLC） | 在分裂点插入节点，分裂后的 segment 独立优化 |
| target_length 滑动 | 几何求解器的连续变量，梯度下降驱动 |
| GND_REF 连接 | 后处理规则引擎：自动在节点处生成接地过孔 |
| component_pad_junction | 节点处叠加寄生电容模型（焊盘比线宽大） |
| 宽度固定约束 | 几何求解器的硬约束（代价函数惩罚项） |
| 禁止区避让 | 几何求解器的约束投影步骤 |

### 6.2 端到端流程示例

```
输入 YAML：
  一条 10mm 微带线，宽 1.0mm，在 4mm 处吸附 5.6pF 接地电容

算法处理：
  1. FLUTE 拓扑规划：识别出 1 条主干（两点直线）
  2. 边分裂：生成 node_shunt_tap，拆分为 4mm + 6mm 两段
  3. 几何求解器：
     - 变量：node_shunt_tap 的位置 t ∈ [0,1]（初始 t=0.4）
     - 梯度：∂E/∂t，计算能量函数最小值
     - 输出：最优 t*，对应最优电容位置
  4. 电弧后处理：弯角处生成弧形曲线
  5. GND_REF 引擎：在 node_shunt_tap 处生成接地过孔

输出：Gerber 布线文件，包含微带线坐标 + 过孔坐标
```

## 7. Apollo 参考实现分析

### 7.1 Apollo 核心思路

Apollo (ScopeX-ASU/Apollo) 是 2024 年的开源单层波导布局布线系统，GitHub star 持续增长。

**架构：**
```
输入：波导拓扑 + 端口位置 + 禁止区
  ↓
GPU 加速布局优化（模拟退火变体）
  ↓
A* 路由器（分通道）
  ↓
输出：GDSII 布局结果
```

**成功率：94.79%**（在标准 benchmark 上）

### 7.2 对本项目的借鉴

| Apollo 模块 | 借鉴点 | 直接使用？ |
|-----------|--------|---------|
| GPU 加速模拟退火 | 多目标能量函数并行评估 | ⭐ 可借鉴思路 |
| A* 路由器 | 栅格化，不适合本场景 | ❌ |
| 热估计模型 | 功放 PCB 热感知布局 | ⭐ 值得参考 |
| 拓扑变形 | 边的分裂/合并 | ✅ 与本场景一致 |

**关键教训：** Apollo 虽然用了 A*，但其波导是矩形截面（与微带线不同），且栅格化是精度换速度的权衡。对本场景，**直接用几何求解器跳过栅格化**，精度更高。

## 8. 结论与决策

### 8.1 最终推荐

**核心算法：几何求解器（梯度下降路径优化）**
- 无栅格化，连续空间最优
- target_length 梯度直接驱动
- 与 Graph-Topology 完美契合

**拓扑规划：FLUTE**
- 主干多点拓扑（功率合成/分配）
- 效率极高，工业验证

**后处理：电弧路由 + GND_REF 规则引擎**
- 高频弯角精度
- 接地过孔自动生成

### 8.2 算法选型决策表

| 场景 | 拓扑规划 | 几何优化 | 后处理 |
|------|---------|---------|-------|
| 标准功放（<10GHz） | FLUTE | 几何求解器 | GND_REF 引擎 |
| 多功率合成（Doherty） | FLUTE | 几何求解器 | GND_REF 引擎 + 电弧（可选） |
| 复杂禁止区 | FLUTE + RRT | 几何求解器 | GND_REF 引擎 |
| 高频毫米波（>10GHz） | FLUTE | 几何求解器 | 电弧路由 + GND_REF 引擎 |
