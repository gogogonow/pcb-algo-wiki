# 布线算法选型对比分析

## 1. 核心数据结构

用户定义的 Graph-Topology 结构本质是**混合图**：

```
节点类型:
  junction              — 纯拓扑交汇点
  component_pad_junction — 元器件焊接点（含寄生参数）
  GND_REF               — 全局地参考节点

边类型:
  microstrip       — 分布参数传输线（width + target_length）
  lumped_RLC       — 集总参数器件（value + package）
```

**关键特性：** `target_length` 是连续滑动变量，边分裂/合并是拓扑操作。

---

## 2. 算法对比矩阵

| 算法 | 搜索空间 | 宽度支持 | 转角精度 | 多线协调 | 拓扑适配度 |
|------|---------|---------|---------|---------|-----------|
| **A\*** | 离散栅格 | 差（需重新栅格化） | 差（对角移动） | 差（依次布会堵路） | ❌ 不适合 |
| **FLUTE** | 连续（查找表） | 良 | 良 | 优（Steiner树构造） | ⭐⭐ 适合主干多点拓扑 |
| **几何求解器** | 连续空间 | 优（无栅格） | 优（clothoid/mitered） | 中 | ⭐⭐⭐ 最适合微带线 |
| **RRT-Connect** | 连续空间 | 优 | 差（随机树） | 差 | ⭐ 适合复杂禁止区 |
| **电弧路由** | 连续空间 | 优 | 最优（弧形弯角） | 中 | ⭐⭐⭐ 弯角精度最高 |

---

## 3. 各类算法对 Graph-Topology 的适配度分析

### A* — ❌ 不推荐

**问题：**
- 栅格化与 `target_length` 滑动冲突：栅格精度决定路径质量，但宽度变化时需要重建栅格
- `mitered` 弯角补偿需要后处理，破坏 A* 最优性
- 多线协调差：先布的边成为后布的边的障碍

**结论：** 不适合本场景的连续参数优化模型。

---

### FLUTE — ⭐⭐ 良（适用于特定拓扑）

**优势：**
- Steiner 树构造适合 Doherty 功放的功率合成/分配结构（多点到多点）
- 工业级验证（Cadence 开源）
- 速度快（查找表而非搜索）

**劣势：**
- 不直接支持 `target_length` 滑动优化
- 不处理 `GND_REF` 吸附点的过孔自动生成

**结论：** 适合**主干总线拓扑**，需与几何求解器组合使用。

---

### 几何求解器（Gradient-Based Path Relaxation）— ⭐⭐⭐ 最佳推荐

**核心思路：**
```
初始路径 → 梯度下降/约束投影优化 → 精确弯角 → 输出
```

**与 Graph-Topology 的契合点：**

| Graph-Topology 特性 | 几何求解器支持方式 |
|---------------------|-------------------|
| `target_length` 滑动 | 路径长度作为优化变量，梯度直接驱动 |
| 边分裂（插入 RLC） | 分裂点位置作为独立变量，梯度优化 |
| 宽度固定 | 代价函数包含线宽约束，无栅格化 |
| `GND_REF` 过孔 | 后处理规则：检测到 GND_REF 连接 → 自动生成过孔 |
| `component_pad_junction` 寄生 | 在节点处叠加寄生参数模型 |

**转角处理：** clothoid 或 mitered 参数曲线，补偿弯角不连续性。

**多线协调：** 可同时优化所有路径（联合优化），而非依次布。

---

### RRT-Connect — ⭐ 补充方案

**适用场景：** 复杂禁止区（异形板框、大量过孔禁入区）+ 初始路径探索。

**问题：** 路径次优，需要后处理平滑（如 gradient descent relaxation）。

**结论：** 作为几何求解器的初始路径提供者，或复杂禁止区时的保底方案。

---

### 电弧路由（Arc Routing）— ⭐⭐⭐ 弯角精度最高

工业 PCB 设计中，弯角通常不是直角也不是 mitered，而是**圆弧（arc）或带切角的弧**。

**优势：**
- 电气性能最优（弧形弯角的阻抗不连续性最小）
- 天然适配传输线理论

**与几何求解器结合：** 几何求解器的后处理阶段用弧形曲线替换尖锐折线。

---

## 4. 推荐方案：两层组合

```
布线策略：
┌─────────────────────────────────────────────────────────────┐
│ 第一层：拓扑层（Topology Planning）                          │
│   输入：Graph-Topology YAML + 板框 DXF                       │
│   输出：微带线主线拓扑（Steiner 树 / 链形 / 星形）             │
│   算法：FLUTE（主干多点拓扑）+ 拓扑分裂操作（边分裂合并）       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ 第二层：几何层（Geometric Optimization）                      │
│   输入：拓扑规划结果 + target_length 约束                     │
│   输出：物理坐标 + 精确路径 + 过孔位置                        │
│   算法：几何求解器（梯度下降 + 弧形弯角后处理）                 │
│   特点：                                                    │
│     · target_length 作为优化变量，梯度直接驱动                 │
│     · 吸附点滑动 → 路径"推拉"式更新                          │
│     · GND_REF → 自动过孔生成规则引擎                         │
└─────────────────────────────────────────────────────────────┘
```

**关键优势：**
- **拓扑与几何解耦**：拓扑优化（结构搜索）和几何优化（参数精化）分开，速度快
- **长度滑动友好**：几何求解器天然支持连续变量
- **工业精度**：弧形弯角补偿，阻抗连续性最佳

---

## 5. 决策建议

| 场景 | 推荐算法 |
|------|---------|
| 标准微带线布线（宽度固定、无复杂禁止区） | 几何求解器（梯度下降） |
| Doherty 多功率合成/分配结构（多点拓扑） | FLUTE + 几何求解器 |
| 复杂禁止区（异形板框） | RRT-Connect + 几何求解器（保底） |
| 高频毫米波（弯角精度要求极高） | 电弧路由 + 几何求解器 |
| 快速原型验证 | A* + 后处理（仅作基准对比） |

**最终推荐：几何求解器（梯度下降路径优化）+ FLUTE（拓扑规划）组合方案。**

该方案与用户定义的 Graph-Topology 数据结构完美契合，拓扑分裂/合并操作可直接映射为优化变量，无需栅格化，精度和速度兼得。
