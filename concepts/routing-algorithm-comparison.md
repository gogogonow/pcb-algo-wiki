# 布线算法选型深度分析报告（复杂场景版）

> 场景升级：固定微带线 + 灵活走线混合 | 高密度 RLC shunt | 无交叉硬约束

---

## 1. 场景重新定义

### 1.1 输入格式（不变）

```yaml
nodes:
  node_A: { type: "junction" }
  node_shunt_tap:
    type: "component_pad_junction"
edges:
  tl_segment_part1:  # 固定微带线段
    type: "microstrip"
    connections: [ "node_A", "node_shunt_tap" ]
    constraint: { width: 1.0, target_length: 4.0, fixed: true }  # fixed=true

  tl_segment_part2:  # 灵活走线段
    type: "microstrip"
    connections: [ "node_shunt_tap", "node_B" ]
    constraint: { width: 1.0, target_length: 6.0, fixed: false }  # fixed=false

  c_shunt_match:  # 高密度RLC shunt
    type: "lumped_capacitor"
    connections: [ "node_shunt_tap", "GND_REF" ]
    parameters: { value_pF: 5.6, package: "0402" }
```

### 1.2 新场景的三个关键变化

| 变化 | 之前（简单场景） | 现在（复杂场景） |
|------|----------------|----------------|
| **线网类型** | 单一微带线 | 固定微带线 + 灵活走线混合 |
| **RLC 密度** | 低（少量 shunt） | 高（大量并联器件） |
| **交叉约束** | 软约束（惩罚项） | **硬约束（绝对不能出现）** |

### 1.3 问题性质的改变

```
之前：局部路径优化
     → 单条线找最优路径，能量函数驱动

现在：全局拥塞避免 + 拓扑感知的多层协调
     → 固定线是动态障碍
     → RLC密度高 → 拓扑分裂频繁
     → 无交叉 = 全局硬约束，不能后处理修复
```

## 2. 算法对比（复杂场景）

### 2.1 对比维度

| 维度 | 说明 |
|------|------|
| **拥塞感知** | 能否评估并绕开全局拥塞区域 |
| **无交叉保证** | 是否能提供硬性无交叉保证（非概率性） |
| **拓扑分裂友好度** | 高密度RLC下频繁边分裂的支持程度 |
| **固定线避让** | 将固定微带线视为动态障碍的能力 |
| **过孔密度控制** | 高密度shunt场景下过孔资源的约束 |

---

### 2.2 算法分类

```
路由算法（复杂场景）
├── 栅格搜索类
│   ├── Lee's Algorithm (迷宫算法) — 无交叉保证，但O(ng)，高密度下崩溃
│   ├── A* + 拥塞代价 — 效率提升，但无交叉保证弱
│   └── NC-A* (No-Crossing A*) — A*改进去填，但复杂场景仍不足
│
├── 几何构造类
│   ├── FLUTE — 拓扑规划优，但无拥塞感知
│   └── 几何求解器 — 精度高，但全局拥塞协调差
│
├── 整数规划类 ⭐⭐⭐⭐
│   ├── ILP (整数线性规划) — 硬约束最强，全局最优保证
│   └── SAT (布尔可满足性) — 无交叉约束编码为boolean公式
│
├── 元启发式类 ⭐⭐⭐
│   ├── 模拟退火 — 全局优化，多目标，但无硬约束保证
│   └── 遗传算法 — 大规模协同，但收敛慢
│
└── 分区分解类 ⭐⭐⭐⭐⭐
    ├── 区域分解 (Zone Decomposition) — 将全局约束降为局部
    ├── Bounded-level Routing — 分层无交叉路由
    └── 迷宫分解 (Maze Decomposition)
```

## 3. 各类算法深度分析

### 3.1 Lee's Algorithm（迷宫算法）— 无交叉保证，但效率崩塌

**核心：** 广度优先展开，保证找到最短路径且无交叉。

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ✅✅✅ | 广度优先天然无交叉 |
| 拥塞感知 | ❌ | 不感知全局拥塞 |
| 拓扑分裂友好 | ❌ | 高密度下状态空间爆炸 |
| 固定线避让 | ⚠️ | 可标记障碍，但无优先级机制 |
| 过孔密度控制 | ❌ | 不考虑过孔资源 |

**致命问题：** 高密度RLC + 固定线混合场景下，时间复杂度 O(ng) 中的 n（节点数）爆炸，Lee算法不可用。

---

### 3.2 A* + 拥塞代价 — 效率优先，保证不足

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ⚠️ | 拥塞代价引导，但无法保证硬约束 |
| 拥塞感知 | ✅ | 拥塞代价项 |
| 拓扑分裂友好 | ❌ | 栅格化与高密度分裂冲突 |
| 固定线避让 | ✅ | 障碍标记 |
| 过孔密度控制 | ❌ | 不考虑过孔资源 |

**问题：** 拥塞代价是"软引导"，无法保证无交叉硬约束。高密度RLC场景下，交叉概率高。

---

### 3.3 NC-A* (No-Crossing A*) — A* 改进版

**核心：** A* 变体，用整数规划后处理消除局部交叉。

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ✅✅ | 整数规划后处理提供理论保证 |
| 拥塞感知 | ✅ | A* 代价函数 |
| 拓扑分裂友好 | ⚠️ | 仍受栅格化影响 |
| 固定线避让 | ✅ | 障碍标记 |
| 过孔密度控制 | ⚠️ | 整数规划可加约束 |

**适用性：** 比原始 A* 强，但栅格化依赖和高密度场景仍是瓶颈。

---

### 3.4 ILP（整数线性规划）— ⭐⭐⭐⭐⭐ 硬约束最优

**核心：** 将所有约束编码为线性/整数约束，求解器求全局最优解。

```math
min  Σ(length_i)
s.t.
  1. path_i 不经过障碍物区域      (binary decision vars)
  2. path_i 与 path_j 无交叉      (mutual exclusion constraints)
  3. path_i 宽度 = w_fixed        (fixed parameter)
  4. 过孔数量 ≤ Via_max           (resource constraint)
  5. 变量离散化 (x_i, y_i ∈ Z)    (integer vars)
```

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ✅✅✅ | 整数约束强制执行 |
| 拥塞感知 | ✅✅ | 目标函数 + 约束可含拥塞项 |
| 拓扑分裂友好 | ✅✅ | 变量数随节点线性增长 |
| 固定线避让 | ✅✅✅ | 障碍约束精确表达 |
| 过孔密度控制 | ✅✅✅ | 约束方程直接限制 |

**优势：**
- 硬约束（无交叉）有理论保证
- 全局最优（而非启发式近似）
- 可精确控制过孔数量

**劣势：**
- 变量数随线网数量指数增长
- 大规模电路（>100节点）求解时间不可控
- 需要商业或高质量开源求解器（Gurobi / CPLEX / SCIP）

**适用性：最适合本场景的算法之一，但需配合分区分解控制规模。**

---

### 3.5 SAT（布尔可满足性）布线 — ⭐⭐⭐⭐ 硬约束好，规模受限

**核心：** 将无交叉约束编码为 SAT formula，用 SAT 求解器求解。

```prolog
% 简化示例：两条线段不能同时占用同一栅格
¬(occupied(cell_1, net_A) ∧ occupied(cell_1, net_B))
```

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ✅✅✅ | SAT公式强制无交叉 |
| 拥塞感知 | ⚠️ | 需扩展编码，规模指数增长 |
| 拓扑分裂友好 | ✅ | 布尔变量按节点定义 |
| 固定线避让 | ✅ | 障碍编码为固定真值 |
| 过孔密度控制 | ⚠️ | 可编码，但变量爆炸 |

**优势：** 无交叉保证强，编码直观。

**劣势：** 变量数指数增长，只适合小规模（<20节点）。

---

### 3.6 模拟退火 + 拥塞惩罚 — ⭐⭐⭐ 全局优化，软约束

**核心：** 随机扰动 + Metropolis准则，多目标能量函数。

```python
E = α·Σlength          # 线长最小化
  + β·crossing_count   # 交叉计数（必须=0）
  + γ·congestion_penalty  # 拥塞惩罚
  + δ·via_count        # 过孔数量
```

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ⚠️ | crossing_count作为惩罚项，理论上可能不为0 |
| 拥塞感知 | ✅✅ | 拥塞惩罚项 |
| 拓扑分裂友好 | ✅✅ | 连续变量，梯度驱动 |
| 固定线避让 | ✅✅ | 障碍惩罚项 |
| 过孔密度控制 | ✅ | 惩罚项 |

**关键问题：** **交叉是硬约束，但模拟退火无法保证 100% 无交叉。** 惩罚项再大也有概率出现交叉。

**改进：** 用"分层模拟退火"——先优化拓扑（无几何感知），再优化几何参数（固定拓扑）。

---

### 3.7 区域分解 (Zone Decomposition) — ⭐⭐⭐⭐⭐ 降复杂度核心

**核心思想：** 将全局无交叉约束从"全局N条线的N×N约束"降为"局部M个区域的M×M约束"。

```
分区策略：
1. 固定微带线 → 占据固定区域（动态障碍）
2. RLC shunt → 按主干线分组，每组一个区域
3. 灵活走线 → 在剩余区域布线

无交叉约束范围：从全局 N×N 降为 区域数 × 区域数
```

| 维度 | 评分 | 说明 |
|------|------|------|
| 无交叉保证 | ✅✅✅ | 区域隔离 = 天然无交叉 |
| 拥塞感知 | ✅✅ | 区域级别拥塞可评估 |
| 拓扑分裂友好 | ✅✅ | 分区边界可适应分裂 |
| 固定线避让 | ✅✅✅ | 固定线直接定义区域边界 |
| 过孔密度控制 | ✅✅ | 区域级别约束 |

**优势：**
- 将全局硬约束问题转化为局部问题
- 规模可控（每个区域单独求解）
- 可与 ILP / 几何求解器 / 模拟退火组合

**与 ILP 的完美组合：** 区域分解 + ILP = 规模可控的无交叉全局最优解。

## 4. 高密度 RLC shunt 的特殊处理

### 4.1 问题

```
高密度 shunt 意味着：
- 大量 node_shunt_tap 节点
- 每吸附一个RLC，拓扑分裂一次
- 分裂后的 segment 仍然需要无交叉路由
- 接地过孔密度可能成为瓶颈
```

### 4.2 策略：Net-Ordering（线网排序）

**核心思想：** 先布约束最严格的线网，后续线网绕开已布线路径。

```
排序规则：
1. 固定微带线 → 最先布（硬约束，不可移动）
2. RF 主干线（宽、微波频段）→ 次布（阻抗敏感）
3. 粗短分支 → 再次（电阻低优先）
4. 细长灵活走线 → 最后（有最多绕行空间）
5. RLC shunt 接地支路 → 按分组依序布
```

### 4.3 过孔密度控制

```yaml
# 在 YAML 中加入过孔预算约束
constraints:
  max_via_count: 50          # 全局最大过孔数
  via_density_threshold: 2/mm²  # 每平方毫米最大过孔数
  via_clusters_forbidden: true   # 禁止过孔扎堆
```

## 5. 最优算法组合方案

### 5.1 核心结论

**对于"固定微带线 + 灵活走线混合 + 高密度 RLC + 无交叉硬约束"场景：**

> **最优方案 = 区域分解 (Zone Decomposition) + ILP + 几何求解器（梯度下降）**

### 5.2 架构

```
┌────────────────────────────────────────────────────────────────┐
│ 第一层：区域分解 (Zone Decomposition)                            │
│                                                                │
│ 输入：Graph-Topology YAML + 板框 DXF                           │
│                                                                │
│ 步骤：                                                          │
│   1. 标记固定微带线占据区域 → 动态障碍                           │
│   2. RLC shunt 按主干分组 → 每组一个区域                        │
│   3. 剩余区域 → 灵活走线可用的自由区域                          │
│                                                                │
│ 输出：区域划分图，每个区域最多包含 N 条局部线网                   │
│                                                                │
│ 关键优势：无交叉约束从全局 N×N 降为 区域数 × 区域数             │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 第二层：Net-Ordering（线网排序）                                 │
│                                                                │
│ 排序规则：                                                      │
│   fixed=true → RF主干 → 粗短分支 → 细长走线 → RLC shunt支路    │
│                                                                │
│ 目的：约束最严格的先布，给后续线网留最大绕行空间                  │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 第三层：ILP（区域级无交叉求解）                                  │
│                                                                │
│ 对每个区域内的线网：                                             │
│   min Σlength                                                    │
│   s.t.                                                          │
│     · 路径不经过障碍物                                          │
│     · 区域内路径两两无交叉                                      │
│     · 过孔数量 ≤ 区域预算                                        │
│     · 宽度 = 固定值（microstrip width）                        │
│                                                                │
│ 求解器：SCIP（开源）或 Gurobi（学术免费）                       │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 第四层：几何求解器（精细化 + 长度滑动优化）                      │
│                                                                │
│ 对 ILP 输出的离散路径：                                        │
│   · 梯度下降路径松弛（连续空间精化）                            │
│   · target_length 滑动优化                                      │
│   · 弧形弯角后处理（高频场景）                                  │
│   · GND_REF 规则引擎（自动过孔生成）                            │
│                                                                │
│ 注意：高密度RLC导致分裂频繁 → 几何求解器快速重优化是关键         │
└────────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────────┐
│ 第五层：全局交叉验证                                             │
│                                                                │
│ 验证：所有区域边界处是否存在跨越                                    │
│ 如果存在：触发区域重划分或局部ILP重求解                         │
│                                                                │
│ 硬约束保证：最后一道防线                                         │
└────────────────────────────────────────────────────────────────┘
```

### 5.3 决策树

```
输入判断：
├── 电路规模 < 20节点（小型）
│   └── ILP直接求解（无需区域分解）
│
├── 电路规模 20-100节点（中大型） + 高密度RLC
│   └── 区域分解（按主干线分组）+ ILP + 几何求解器
│
├── 电路规模 > 100节点（大型）
│   ├── 分层区域分解（hierarchical zone decomposition）
│   ├── 上层：粗略拓扑规划（FLUTE）
│   └── 下层：区域内 ILP + 几何求解器
│
└── 高频毫米波场景（>10GHz）
    └── 几何求解器层加强：弧形弯角补偿（必须）
```

## 6. 与简单场景的算法对比

| 场景 | 最优算法组合 | 核心差异 |
|------|------------|---------|
| **简单场景**（固定微带线、低密度RLC、软约束） | 几何求解器 + FLUTE + 电弧后处理 | 无需ILP，规模可控 |
| **复杂场景**（混合线网、高密度RLC、无交叉硬约束） | 区域分解 + ILP + 几何求解器 | **ILP保证硬约束，区域分解控规模** |

## 8. 关键结论

### 8.1 算法选型决策

**简单场景：**
```
几何求解器（梯度下降）+ FLUTE + 电弧后处理
```

**复杂场景（当前）：**
```
区域分解 + ILP + 几何求解器 + FLUTE（拓扑规划）
```

### 8.2 为什么模拟退火不够？

| 问题 | 说明 |
|------|------|
| 交叉是**硬约束** | 模拟退火用惩罚项，理论上存在交叉概率 |
| 高密度RLC | 惩罚项空间复杂，惩罚系数难以设置 |
| 固定线混合 | 扰动操作可能破坏固定线位置 |

**ILP + 区域分解** 是唯一能提供**硬性无交叉保证**同时**规模可控**的方案。

### 8.3 下一步行动

1. **实现区域分解算法**：将板面按固定微带线 + 主干线分组
2. **集成 ILP 求解器**：SCIP（开源）或 Gurobi（学术免费）
3. **实现 Net-Ordering**：按约束严格程度排序线网
4. **验证对比实验**：对比 ILP 方案 vs 模拟退火方案在无交叉通过率上的差异
